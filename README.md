# Trade Connector example server

An example integration with the [Trade Connector](https://tradeconnector.com.au) Partner API v1:
create jobs, follow them through their lifecycle in sandbox mode, and receive and verify webhooks.

Use it to see how a connection to Trade Connector works, or copy the code into your own system.
It is MIT licensed, so you can use it in commercial software.

> Work in progress. The first version is being built now.
